# 二进制身份

`openshell-binary-identity` 为 RFC 0012 隔离后端提供共享的可执行文件身份解析。运行时特定的观察器仍留在各自后端：Docker 从 seccomp 通知中获取权威线程 ID，而同机 Linux 路径则将已接受的套接字映射到其所属进程。

给定权威 Linux PID 和可选的受信任进程树根，该 crate 会打开叶子及有界祖先的 `/proc/<pid>/exe` 对象，对这些已打开的活对象计算哈希，并返回整条可执行链的路径与摘要证据。它还会收集诊断用的命令行路径，这些路径从不用于授权网络访问。若任一可执行文件无法打开、无法哈希，或哈希后无法验证，解析即失败，不返回部分身份。调用方收到 `ResolveError` 并拒绝相关连接。

该 crate 不拦截连接、不认证远程观察器，也不评估策略。隔离后端仍负责在构造 `PendingTcpOpen` 之前，将解析出的身份绑定到活动边界和确切已接受的连接。
