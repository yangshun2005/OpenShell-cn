# 沙箱运行时

`openshell-sandbox` 负责 Linux 工作负载隔离机制及其内核资格探测。`linux` 模块包含 seccomp 通知与子过滤器、任务内存访问、进程信号中介、procfs 描述符查找、套接字身份、Landlock 资格以及工作负载启动线程。

`sandbox::linux` 负责组合策略执行。顶层 `linux` 模块拥有该编排和边界服务器所使用的底层机制。不安全的 kernel ABI、进程启动和描述符所有权操作保留在此运行时 crate 中，置于可强制执行其契约的安全 API 之后。

网络代理仅在准备工作负载端点期间保留源套接字描述符。连接成功或 `listen` 后即释放该引用；此后内核通过工作负载持有的描述符跟踪生命周期。原生 `accept` 和重复 `listen` 会保持套接字的回环限制。关闭工作负载对监听器的最后一个引用即将其移除，无需等待注册表回收。代理源描述符始终使用 close-on-exec，与工作负载请求的描述符标志无关。

配置为 `RuntimeInitiatedTlsTcp` 的边界不绑定任何监听器。它仅拨号驱动提供的监督者地址，这些地址必须是具体的、非回环的，且共享同一端口，并在该出站连接上提供 TLS 和 gRPC。它保留一条监督者尚未使用的备用连接，当监督者在其上启动 HTTP/2 或备用连接关闭时拨号替换连接。活动连接保持与监听器模式相同的断开、冻结和恢复截止时间处理，工作负载仍无法连接到控制端口。
