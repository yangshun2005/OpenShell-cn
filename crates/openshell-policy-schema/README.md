# openshell-policy-schema

规范化的作者策略类型、有界 YAML 解析和纯校验。
运行时强制执行和 protobuf 适配不在本 crate 范围内。

`yaml` 模块提供共享的作者数据兼容边界，供策略、provider-profile 和 prover 加载器以及 CLI YAML 输出使用。每个加载器声明必须在普通 Serde 解码前拒绝 null 的 Schema 对象路径。可选对象和无类型用户数据值保留其常规 null 语义。空或 null 的顶层文档会被拒绝。加载器在解码其类型化 Schema 前拒绝重复的映射键。

策略解析保留其显式资源预算和字段路径诊断。YAML 导出会对旧版读取器可能解释为日期、数字或布尔值的字符串和映射键加引号，但不改变实际的数值或布尔数据。对已生成的输出进行格式化不会施加新的输入大小限制。
